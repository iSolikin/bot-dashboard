# Bot Dashboard

**Локальная панель для наблюдения за автоматизацией.** Собирает сведения о работе нескольких ботов в одном месте, чтобы быстрее замечать остановки и ошибки.

## Возможности

- Показывает события, состояние и историю работы подключённых ботов.
- Помогает просматривать профили и сводки по отдельным процессам.
- Поддерживает регулярные отчёты и проверки состояния.

Панель рассчитана на настройку под конкретный набор ботов и окружение.
