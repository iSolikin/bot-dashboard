# Bot Dashboard

Одна панель для нескольких ботов. Помогает быстро увидеть, какие процессы работают, где возникла ошибка и что изменилось за день.

### В панели

- Состояние подключённых ботов и лента событий.
- История по отдельным профилям.
- Сводки и регулярные проверки.

Панель настраивается под ваши процессы и может дополнять уже работающую автоматизацию.
